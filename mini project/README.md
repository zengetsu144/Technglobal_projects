# Movie Recommendation System

A Data Science minor project that recommends movies using **content-based filtering**, **collaborative filtering (SVD)** and a **hybrid** of both, built on the MovieLens 100k dataset.

**Author:** Soumya, BTech CSE, KIIT University

## Features

- Content-based similarity: finds movies with similar genres.
- Collaborative filtering: SVD matrix factorisation (Surprise library) predicts ratings for movies a user hasn't seen.
- Hybrid recommender: 70% collaborative score + 30% genre match to the user's liked movies (rated 4 or above).
- Evaluation with RMSE and MAE on an 80/20 train-test split.
- Exploratory analysis: rating statistics, sparsity and a rating distribution plot.

## Dataset

- **Name:** MovieLens 100k
- **Source:** GroupLens Research, University of Minnesota
- **Size:** 100,000 ratings from 943 users on 1,682 movies
- **Download:** https://grouplens.org/datasets/movielens/100k (direct zip: https://files.grouplens.org/datasets/movielens/ml-100k.zip)

The dataset is not included in this repo. Download and unzip it so an `ml-100k` folder sits next to the script.

## How to Run

```bash
pip install pandas numpy scikit-learn scikit-surprise matplotlib
python movie_recommender.py
```

The script prints dataset statistics, RMSE and MAE, similar movies for a sample title, and top-10 recommendations (collaborative and hybrid) for a sample user. It also saves `rating_distribution.png`.

To try other inputs, edit the last lines of `movie_recommender.py`: the movie title passed to `similar_movies()` and the user ID passed to `recommend_cf()` and `recommend_hybrid()`.

## Methodology

1. **Define:** hybrid recommender combining content-based and collaborative filtering.
2. **Collect:** ratings (`u.data`) and movie metadata (`u.item`).
3. **Preprocess:** drop nulls and duplicates; normalise genre vectors.
4. **Explore:** rating distribution, sparsity, user-item interactions.
5. **Model behaviour:** cosine similarity between movies using genre vectors.
6. **Build:** SVD (100 factors, 30 epochs) trained on 80% of ratings.
7. **Recommend:** top-N unseen movies per user.
8. **Evaluate:** RMSE and MAE on the 20% test split.
9. **Optimise:** tune `n_factors`, `n_epochs` and the hybrid weight.
10. **Document:** this README.

## Limitations

- **Cold start:** new users or movies with no ratings can't get collaborative recommendations.
- **Sparsity:** most user-movie pairs are unrated, which limits accuracy.
- **Content features:** only genres are used; plot, cast and director are ignored.
- **Dataset age:** MovieLens 100k dates from 1998, so recent movies aren't covered.
- **Hybrid weights:** the 70/30 split is a fixed choice, not learned.

## Future Work
